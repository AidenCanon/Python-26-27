# Week 7 - Project Framing Example

## Project Name
-	Task Tracker Application
---

## Purpose

-	The purpose of this is to help a college student track assignments and the date they are due with the time they would like to spend on each assignment.

---

## User

A student using console based program in python.

---

## Inputs

-	Assignment course
-	Assignment Name
-	Assignment Date due
-	How long you would like to spend on this assignment.

---

## Outputs

-	Total minutes the student would like to spend on this assignment 
-	Whether or not the student should take a break

---

## Constraints

-	Timeline by this I mean amount of time for the assignment
-	Must remain small for a console application
-	Should use concepts already learned in class

---

## Likely Structure

-	List of dictionaries
-	Functions for adding, and displaying


---

## Risks or Unknowns

-	Input Gets saved at a later date
-	If the console would grow would it still work 
-	Keeping it tidy could be a risk I feel as with any of them

---

## AI-Use Boundaries

AI may help:

- suggest alternate function names
- draft a first version of a summary function
- compare organizational options

AI may not decide:

- the project purpose
- whether the project is too large
- what counts as a successful final build
