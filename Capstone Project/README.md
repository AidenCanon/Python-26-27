# Assignment Task Tracker 
---
A working console demo of my capstone proposal and it supports the build justification.
---
##  What Application Does 
User can add assignments for a task for multiple courses, list tasks, date, tasks, and mark pending or complete.
---
## Requirements and running  
The user will need python installed specifically the latest version.

The user will need to download the Capstone project and if zipped un zip it. 
The user should then open the capstone folder into the terminal.

Choose an option from the menu:

1. Add Tasks
2. List Tasks
3. Exit

When adding a task the minutes needs to be a whole number and above zero. when adding a date the format needs to be MM-DD-YYYY with the dashes as showed here and in the console.
---
## Validation Check 
To run a validation check Type this into the console input twice 

* Course: Python 
* Assignment: Capstone 
* Due Date: 10-6-2026
* Minutes: 15
* Status: Pending 

* Expected when ran twice 

* Total minutes should equal out to 30
