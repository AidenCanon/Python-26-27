## 2. Why I Chose It

## 3. How It Works

* The application displays a menu with options to Add a task, list a task, or exit the program.  
*  When adding the the user will put in the course, assignment, due date, and minutes you plan to take on the assignment.
* Each task is stored in a dictionaries and all of the task together are in a list.
* The program does go through and check if the date that is put in is valid also it makes sure that the minutes are positive and not 0.
